# Panel de desarrollo (`devtools`) Implementation Plan

> **Para agentes:** SUB-SKILL REQUERIDA: usa `superpowers:subagent-driven-development` (recomendada) o `superpowers:executing-plans`
> para implementar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para seguimiento.

**Objetivo:** una página local, solo de desarrollo y solo lectura, que muestre las ejecuciones de Step Functions (con su línea de tiempo), las colas SQS y los tópicos de Kafka.

**Arquitectura:** un servicio FastAPI (`local/devtools/`) consulta LocalStack con boto3 y Kafka con aiokafka, y sirve una sola página HTML que consulta `/api/*` cada 3 s. Cada consulta va envuelta
para que una dependencia caída marque solo su panel como «no disponible».

**Tecnología:** Python 3.12, FastAPI, uvicorn, boto3, aiokafka 0.14.0, pytest + pytest-asyncio + httpx, HTML/CSS/JS sin build, Docker Compose.

**Especificación:** `docs/superpowers/specs/2026-10-02-devtools-design.md`. Léela antes de empezar.

## Restricciones globales

Valen para **todas** las tareas.

- El código vive en `prisma-aws/local/devtools/`. **La raíz no es un repo**: no hay commits en este plan (los archivos se editan y se prueban, no se commitean). No se toca ningún repo de servicio.
- **Solo lectura.** Prohibido llamar `receive_message`, `purge_queue`, `stop_execution`, `start_execution`, `create_topic` o cualquier operación que cambie estado. Solo `list_*`, `describe_*`, `get_*`.
- **No se leen contenidos de mensajes** ni de SQS ni de Kafka. La página muestra datos de la API con `textContent`, **nunca** `innerHTML`.
- Una dependencia caída **nunca** produce un 5xx: responde `200` con `{"available": false, "error": "<clase de la excepción>"}`. Cada consulta tiene un tope de 5 s.
- Puerto `3030`, publicado solo como `127.0.0.1:3030:3030`. Sin pipeline de ECR ni Terraform.
- Variables: `AWS_ENDPOINT_URL`, `AWS_DEFAULT_REGION`, `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY` (falsas), `SFN_STATE_MACHINE_ARN`, `KAFKA_BOOTSTRAP_SERVERS`, `PORT=3030`.
- Textos y comentarios en español de Chile (tuteo), sin voseo.

## Foco de revisión

Entradas y fallas que la especificación implica pero que ninguna prueba "de paso" cubriría; cada una tiene su test en la tarea indicada.

1. **LocalStack o Kafka caídos** → `200` con `available: false`, nunca 5xx ni excepción sin capturar. *(Tareas 1 y 5)*
2. **La máquina de estados aún no existe** (LocalStack recién arrancado) → lista vacía con una nota, no un error. *(Tarea 3)*
3. **Nombre de ejecución inexistente** → `404`, no `500`. *(Tareas 3 y 5)*
4. **Kafka sin tópicos o con un tópico vacío** → listas vacías y `messages: 0`, sin división ni índice fuera de rango. *(Tarea 4)*
5. **Textos del historial con HTML** (`cause` o `error` con `<script>`) → la página los muestra como texto. *(Tarea 6)*

```python
"""Utilidades comunes: toda consulta a una dependencia (LocalStack, Kafka) pasa por `guarded`."""
import asyncio

TIMEOUT_SECONDS = 5.0


async def guarded(fn, *args, timeout: float = TIMEOUT_SECONDS) -> dict:
    """Ejecuta `await fn(*args)` (debe devolver un dict) con tope de tiempo.

    Una dependencia caída o lenta no debe tumbar la API: se responde 200 con `available: false` y la clase de la
    excepción (nunca su texto, que podría traer direcciones internas), y la página marca solo ese panel.
    """
    try:
        data = await asyncio.wait_for(fn(*args), timeout)
        return {"available": True, **data}
    except Exception as exc:  # noqa: BLE001 — cualquier fallo de la dependencia es "no disponible"
        return {"available": False, "error": type(exc).__name__}
```

```python
"""Colas SQS de LocalStack: contadores y DLQ. SOLO lectura: jamás se recibe ni se borra un mensaje (alteraría lo observado)."""
import asyncio
import json

import boto3


def _client():
    return boto3.client("sqs")          # respeta AWS_ENDPOINT_URL / AWS_DEFAULT_REGION


def _listar() -> dict:
    sqs = _client()
    urls = sqs.list_queues().get("QueueUrls", [])
    colas, destinos = [], set()
    for url in urls:
        attrs = sqs.get_queue_attributes(QueueUrl=url, AttributeNames=["All"])["Attributes"]
        dlq = None
        if attrs.get("RedrivePolicy"):
            dlq = json.loads(attrs["RedrivePolicy"])["deadLetterTargetArn"].rsplit(":", 1)[-1]
            destinos.add(dlq)
        colas.append({
            "name": url.rsplit("/", 1)[-1],
            "visible": int(attrs.get("ApproximateNumberOfMessages", 0)),
            "in_flight": int(attrs.get("ApproximateNumberOfMessagesNotVisible", 0)),
            "delayed": int(attrs.get("ApproximateNumberOfMessagesDelayed", 0)),
            "dlq": dlq,
            "is_dlq": False,
        })
    for cola in colas:
        cola["is_dlq"] = cola["name"] in destinos
    return {"queues": colas}


async def list_queues() -> dict:
    return await asyncio.to_thread(_listar)
```

```python
import asyncio
import os
from datetime import datetime, timezone

import boto3
from botocore.exceptions import ClientError

MAX_EVENTOS = 200
MAX_CAUSA = 300


class ExecutionNotFound(Exception):
    """La ejecución pedida no existe."""


def _client():
    return boto3.client("stepfunctions")        # respeta AWS_ENDPOINT_URL / AWS_DEFAULT_REGION


def _arn_maquina() -> str:
    return os.environ["SFN_STATE_MACHINE_ARN"]


def _arn_ejecucion(nombre: str) -> str:
    return _arn_maquina().replace(":stateMachine:", ":execution:") + f":{nombre}"


def _ahora() -> datetime:
    return datetime.now(timezone.utc)


def _iso(fecha) -> str | None:
    return fecha.isoformat() if fecha else None


def _ms(inicio, fin) -> int:
    return max(0, int(((fin or _ahora()) - inicio).total_seconds() * 1000))


# ── lista ───────────────────────────────────────────────────────────────────
def _listar(status, limit) -> dict:
    kwargs = {"stateMachineArn": _arn_maquina(), "maxResults": limit}
    if status:
        kwargs["statusFilter"] = status
    try:
        items = _client().list_executions(**kwargs)["executions"]
    except ClientError as exc:
        if exc.response["Error"]["Code"] == "StateMachineDoesNotExist":
            return {"executions": [], "note": "la máquina prisma-flujo no existe todavía"}
        raise
    return {"executions": [
        {
            "name": e["name"],
            "status": e["status"],
            "start": _iso(e["startDate"]),
            "stop": _iso(e.get("stopDate")),
            "duration_ms": _ms(e["startDate"], e.get("stopDate")),
        }
        for e in items
    ]}


async def list_executions(status: str | None = None, limit: int = 50) -> dict:
    return await asyncio.to_thread(_listar, status, limit)


# ── línea de tiempo ─────────────────────────────────────────────────────────
_FALLAS = {
    "TaskFailed": "failed", "TaskTimedOut": "failed", "LambdaFunctionFailed": "failed", "LambdaFunctionTimedOut": "failed",
    "ExecutionFailed": "failed", "ExecutionTimedOut": "failed", "ExecutionAborted": "aborted",
}


def _armar_pasos(eventos: list) -> list:
    pasos, veces, actual = [], {}, None
    for ev in eventos:
        tipo, ts = ev["type"], ev["timestamp"]
        if tipo.endswith("StateEntered"):
            nombre = ev["stateEnteredEventDetails"]["name"]
            veces[nombre] = veces.get(nombre, 0) + 1
            actual = {"name": nombre, "type": tipo[: -len("StateEntered")], "start": ts, "end": None, "status": "running",
                      "error": None, "cause": None, "attempt": veces[nombre], "retries": 0, "_programadas": 0}
            pasos.append(actual)
        elif tipo.endswith("StateExited") and actual is not None:
            actual["end"] = ts
            if actual["status"] == "running":
                actual["status"] = "ok"
        elif tipo == "TaskScheduled" and actual is not None:
            actual["_programadas"] += 1
            actual["retries"] = actual["_programadas"] - 1
        elif tipo in _FALLAS and actual is not None:
            detalle = ev.get(tipo[0].lower() + tipo[1:] + "EventDetails", {})
            actual["status"] = _FALLAS[tipo]
            actual["error"] = detalle.get("error") or None
            actual["cause"] = (detalle.get("cause") or "")[:MAX_CAUSA] or None
    return [
        {
            "name": p["name"], "type": p["type"], "start": _iso(p["start"]), "end": _iso(p["end"]),
            "duration_ms": _ms(p["start"], p["end"]), "status": p["status"], "error": p["error"], "cause": p["cause"],
            "attempt": p["attempt"], "retries": p["retries"],
        }
        for p in pasos
    ]


def _linea_de_tiempo(nombre: str) -> dict:
    cli = _client()
    arn = _arn_ejecucion(nombre)
    try:
        d = cli.describe_execution(executionArn=arn)
    except ClientError as exc:
        if exc.response["Error"]["Code"] == "ExecutionDoesNotExist":
            raise ExecutionNotFound(nombre) from exc
        raise
    eventos = cli.get_execution_history(executionArn=arn, maxResults=MAX_EVENTOS, reverseOrder=False)["events"]
    return {
        "name": nombre, "status": d["status"], "start": _iso(d["startDate"]), "stop": _iso(d.get("stopDate")),
        "steps": _armar_pasos(eventos),
    }


async def execution_timeline(nombre: str) -> dict:
    return await asyncio.to_thread(_linea_de_tiempo, nombre)
```

```python
"""Kafka: tópicos, mensajes y lag por grupo. SOLO lectura (metadatos y offsets); jamás se consumen ni se leen mensajes."""
import os

from aiokafka import AIOKafkaConsumer, TopicPartition
from aiokafka.admin import AIOKafkaAdminClient


def summarize(partitions: dict, beginning: dict, end: dict, committed: dict) -> dict:
    """Arma la respuesta a partir de offsets ya leídos (función pura: es lo que se prueba con tests)."""
    topics = [
        {
            "name": topic,
            "partitions": len(parts),
            "messages": sum(end[(topic, p)] - beginning[(topic, p)] for p in parts),
        }
        for topic, parts in partitions.items()
    ]
    groups = []
    for group, offsets in committed.items():
        por_topico: dict = {}
        for (topic, partition), offset in offsets.items():
            if (topic, partition) in end:
                por_topico[topic] = por_topico.get(topic, 0) + max(0, end[(topic, partition)] - offset)
        if not por_topico:
            groups.append({"group": group, "topic": None, "lag": None})
        for topic, lag in por_topico.items():
            groups.append({"group": group, "topic": topic, "lag": lag})
    return {"topics": topics, "groups": groups}


def _bootstrap() -> str:
    return os.environ.get("KAFKA_BOOTSTRAP_SERVERS", "kafka:9092")


async def kafka_overview() -> dict:
    admin = AIOKafkaAdminClient(bootstrap_servers=_bootstrap())
    await admin.start()
    try:
        nombres = [t for t in await admin.list_topics() if not t.startswith("__")]       # sin los tópicos internos
        descritos = await admin.describe_topics(nombres) if nombres else []
        partitions = {d["topic"]: sorted(p["partition"] for p in d["partitions"]) for d in descritos}
        tps = [TopicPartition(t, p) for t, ps in partitions.items() for p in ps]

        beginning, end = {}, {}
        if tps:
            consumidor = AIOKafkaConsumer(bootstrap_servers=_bootstrap(), group_id=None)     # sin grupo: no altera ninguno
            await consumidor.start()
            try:
                beginning = {(tp.topic, tp.partition): o for tp, o in (await consumidor.beginning_offsets(tps)).items()}
                end = {(tp.topic, tp.partition): o for tp, o in (await consumidor.end_offsets(tps)).items()}
            finally:
                await consumidor.stop()

        committed = {}
        for group, _tipo in await admin.list_consumer_groups():
            offsets = await admin.list_consumer_group_offsets(group)
            committed[group] = {(tp.topic, tp.partition): meta.offset for tp, meta in offsets.items()}
        return summarize(partitions, beginning, end, committed)
    finally:
        await admin.close()
```

```python
"""API del panel de desarrollo. SOLO lectura y SOLO local: no tiene autenticación y no se despliega a AWS."""
import os
from pathlib import Path
from typing import Literal, Optional

from fastapi import FastAPI, HTTPException, Path as RutaParam, Query
from fastapi.staticfiles import StaticFiles

from app import kafka_view, queues, sfn
from app.common import guarded

app = FastAPI(title="prisma-devtools", docs_url=None, redoc_url=None)

Estado = Literal["RUNNING", "SUCCEEDED", "FAILED", "TIMED_OUT", "ABORTED"]


@app.get("/health")
async def health():
    return {"status": "ok"}


@app.get("/api/executions")
async def executions(status: Optional[Estado] = None, limit: int = Query(50, ge=1, le=200)):
    return await guarded(sfn.list_executions, status, limit)


@app.get("/api/executions/{name}")
async def execution(name: str = RutaParam(pattern=r"^[A-Za-z0-9._-]{1,80}$")):
    try:
        data = await sfn.execution_timeline(name)
    except sfn.ExecutionNotFound:
        raise HTTPException(status_code=404, detail="La ejecución no existe")
    except Exception as exc:  # noqa: BLE001 — dependencia caída: se marca el panel, no se rompe la API
        return {"available": False, "error": type(exc).__name__}
    return {"available": True, **data}


@app.get("/api/queues")
async def colas():
    return await guarded(queues.list_queues)


@app.get("/api/kafka")
async def kafka():
    return await guarded(kafka_view.kafka_overview)


# La página va al final: así `/api/*` y `/health` tienen prioridad sobre los archivos estáticos.
_WEB = Path(__file__).resolve().parent.parent / "web"
if _WEB.is_dir():
    app.mount("/", StaticFiles(directory=_WEB, html=True), name="web")
```

Nota: `execution()` no usa `guarded` porque necesita distinguir el 404 (ejecución inexistente) de una dependencia caída; la excepción de tiempo se cubre porque `boto3` tiene sus propios tiempos de espera y `asyncio.to_thread` no bloquea la API.

```html
  // Regla de seguridad: los datos de la API se escriben SIEMPRE con textContent (nunca como HTML).
  const $ = (id) => document.getElementById(id);
  const el = (tag, clase, texto) => {
    const n = document.createElement(tag);
    if (clase) n.className = clase;
    if (texto !== undefined && texto !== null) n.textContent = texto;
    return n;
  };
  const hora = (iso) => (iso ? new Date(iso).toLocaleTimeString() : '—');
  const dur = (ms) => (ms == null ? '—' : ms < 1000 ? `${ms} ms` : ms < 60000 ? `${(ms / 1000).toFixed(1)} s` : `${Math.floor(ms / 60000)} min ${Math.round((ms % 60000) / 1000)} s`);
  const nuevo = (padre, hijos) => { padre.replaceChildren(...hijos); };

  let pausado = false;
  let seleccionada = null;

  async function pedir(ruta) {
    const r = await fetch(ruta);
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    return r.json();
  }

  function meta(id, datos, extra) {
    const m = $(id);
    m.className = 'meta' + (datos.available === false ? ' aviso' : '');
    m.textContent = datos.available === false
      ? `no disponible: ${datos.error}`
      : `actualizado ${new Date().toLocaleTimeString()}${extra ? ' · ' + extra : ''}`;
  }

  async function ejecuciones() {
    const estado = $('filtro').value;
    const d = await pedir('/api/executions' + (estado ? `?status=${encodeURIComponent(estado)}` : ''));
    meta('meta-ejecuciones', d, d.note);
    if (d.available === false) { nuevo($('filas-ejecuciones'), []); return; }
    const filas = d.executions.map((e) => {
      const tr = el('tr', e.name === seleccionada ? 'sel' : '');
      tr.dataset.name = e.name;
      tr.append(el('td', 'mono', e.name), el('td'), el('td', '', hora(e.start)), el('td', '', dur(e.duration_ms)));
      tr.children[1].append(el('span', `pill ${e.status}`, e.status));
      tr.addEventListener('click', () => { seleccionada = e.name; detalle(); ejecuciones(); });
      return tr;
    });
    if (!filas.length) { const tr = el('tr'); const td = el('td', 'vacio', 'sin ejecuciones'); td.colSpan = 4; tr.append(td); filas.push(tr); }
    nuevo($('filas-ejecuciones'), filas);
  }

  async function detalle() {
    const caja = $('detalle');
    if (!seleccionada) { caja.hidden = true; return; }
    let d;
    try { d = await pedir(`/api/executions/${encodeURIComponent(seleccionada)}`); }
    catch (e) { caja.hidden = false; nuevo(caja, [el('div', 'vacio', 'esa ejecución ya no existe')]); return; }
    caja.hidden = false;
    if (d.available === false) { nuevo(caja, [el('div', 'aviso', `no disponible: ${d.error}`)]); return; }
    const total = Math.max(1, ...d.steps.map((s) => s.duration_ms));
    const cab = el('div', 'meta');
    cab.append(el('span', `pill ${d.status}`, d.status), document.createTextNode(` ${d.name}`));
    const pasos = d.steps.map((s) => {
      const f = el('div', `paso ${s.status}`);
      const nombre = el('div', 'mono', `${s.name}${s.attempt > 1 ? ' #' + s.attempt : ''}${s.retries ? ' · ' + s.retries + ' reintento(s)' : ''}`);
      const barra = el('div', 'barra'); const i = el('i'); i.style.width = `${Math.max(1, (s.duration_ms / total) * 100)}%`; barra.append(i);
      f.append(nombre, barra, el('div', 'mono', dur(s.duration_ms)));
      if (s.error || s.cause) f.append(el('div', 'error', [s.error, s.cause].filter(Boolean).join(' — ')));
      return f;
    });
    nuevo(caja, [cab, ...pasos]);
  }

  async function colas() {
    const d = await pedir('/api/queues');
    meta('meta-colas', d);
    if (d.available === false) { nuevo($('tarjetas-colas'), []); return; }
    const tarjetas = d.queues.map((q) => {
      const c = el('div', 'card' + (q.is_dlq && q.visible > 0 ? ' dlq-con' : ''));
      c.append(el('h3', '', q.name + (q.is_dlq ? ' (DLQ)' : '')));
      const dl = el('dl');
      [['pendientes', q.visible], ['en vuelo', q.in_flight], ['retrasados', q.delayed], ['DLQ', q.dlq || '—']].forEach(([k, v]) => dl.append(el('dt', '', k), el('dd', '', v)));
      c.append(dl);
      return c;
    });
    nuevo($('tarjetas-colas'), tarjetas.length ? tarjetas : [el('div', 'vacio', 'sin colas')]);
  }

  async function kafka() {
    const d = await pedir('/api/kafka');
    meta('meta-kafka', d);
    if (d.available === false) { nuevo($('filas-topicos'), []); nuevo($('filas-grupos'), []); return; }
    const fila = (...celdas) => { const tr = el('tr'); celdas.forEach((c) => tr.append(el('td', '', c))); return tr; };
    nuevo($('filas-topicos'), d.topics.map((t) => fila(t.name, t.partitions, t.messages)));
    nuevo($('filas-grupos'), d.groups.map((g) => fila(g.group, g.topic ?? '—', g.lag ?? '—')));
  }

  async function refrescar() {
    if (pausado) return;
    await Promise.allSettled([ejecuciones(), colas(), kafka(), detalle()]);
  }

  $('pausa').addEventListener('click', () => { pausado = !pausado; $('pausa').textContent = pausado ? 'Reanudar' : 'Pausar'; });
  $('filtro').addEventListener('change', () => { pausado = false; $('pausa').textContent = 'Pausar'; refrescar(); });
  refrescar();
  setInterval(refrescar, 3000);
```
